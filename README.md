# SCM 발주·입고관리 프로토타입

PRD 기반 1차 프로토타입입니다. 전체 업무 흐름을 화면으로 확인하는 데 초점을 두었으며, 샘플 데이터와 브라우저 LocalStorage를 사용합니다.

## 실행

```bash
npm.cmd install
npm.cmd run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 이번 단계 포함 범위

- OL 취합부터 입고·지급까지 0~7단계 네비게이션
- 단계별 핵심 데이터 요약과 샘플 테이블
- LocalStorage 자동 저장
- 샘플 데이터 초기화
- 단계 완료 후 다음 단계 이동
- 단계별 검증·경고·정보 메시지

상세 행 편집, 실제 발주 계산, 보고서 출력, FX-LIVE 연계, 입고·PO Match 처리 로직은 화면 흐름 승인 후 다음 단계에서 구현합니다.
